# IDTC v2 — design workspace

Everything here was made for the idtc.online redesign (2026-10-11). The owner approves this design before the site is built.

- `source-images/` — original PNGs generated with ChatGPT (via Claude in Chrome). Website art: hero, solar, wind, storage, lock, bridge, cover, wave.
- `logo/` — new trading-board token icon. Option A (navy disc, `logo-a1.png`, real alpha) and option B (green disc, `logo-b1-alpha.png`; ChatGPT painted a checkerboard, re-masked to a circle).
- `mockup/` — the clickable prototype (`index.html` + `img/`), published as a private claude.ai artifact.
- `video/` — explainer script (English VO, Thai subtitles) and presenter stills p1–p3.
- `og/` — Open Graph share images as HTML (`og.th.html` → `public_html/images/brand/og.jpg`, `og.en.html` → `og-en.jpg`). Render 1200×630 with Playwright (Edge/Chromium, Google Fonts) and save as JPEG.

Illustrative renders are labelled ภาพประกอบ on the site and are never presented as real projects.
